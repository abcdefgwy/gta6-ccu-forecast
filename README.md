A deterministic Python 3.13 time series forecaster designed for multi-quantile pinball loss evaluation on the [make.fun bounty](https://make.fun/bounty/gta6-twitch-ccu-forecast-01).

## Approach
- Asymmetric pinball loss optimization
- Scale-weighted conditional distribution estimation
- Robust scale tracking via Median Absolute Deviation (MAD)
- Strictly standard-library only
